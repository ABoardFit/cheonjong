# 천종지자 — 화산의 시련

브라우저에서 바로 하는 화산 전투 시제품. **[게임 열기](https://aboardfit.github.io/cheonjong/)**

WASD/방향키 이동, 자동 검격, Space 경공, Esc 일시정지, Tab 능력치. 휴대폰은 전장을 누른 채 끌어 이동한다.

## 메인 화면 수정 도구

메인 화면 상단 **수정** 버튼을 켜면 각 부분에 이름표가 붙고, 눌러서 이름·글자·요청 메모를 적거나 끌어서 옮기고 크기를 바꾸고, 버튼·글·영역을 새로 넣을 수 있다. Shift+클릭이나 빈 곳 드래그로 여러 개를 고르고, 상단 정렬(좌·가로 중앙·우·상·세로 중앙·하)로 메인 화면 또는 Alt+클릭한 기준 요소에 맞춘다. 크기 점을 Shift와 함께 끌면 비율(글자 크기 포함)을 유지한다. 순서 버튼으로 겹침 순서를 바꾸고, 묶음 영역은 **묶음 해제**(Ctrl+Shift+G)로 풀어 안의 요소를 따로 다룬다(툴바의 "묶음 다시 묶기"로 되돌림). 바꾼 내용은 그 브라우저에만 저장되며, **요청서 복사**로 변경 목록을 글로 받아 전달한다. 원본은 `editor/`에 있고 `publish.mjs`가 게임 페이지에 끼워 넣는다.

## 갱신

`docs/`는 GitHub Pages(main 브랜치 `/docs`)가 그대로 서비스한다. 직접 고치지 말고 게임 저장소의 커밋에서 다시 내보낸다.

```bash
node publish.mjs <게임 저장소 경로>
git add -A
git commit -m "deploy: 게임 <커밋>"
git push
```

`publish.mjs`는 게임 저장소 HEAD의 `prototype/dist`만 복사하며(QA 비교 페이지·이미지 프롬프트 제외), 커밋하지 않은 작업은 올라가지 않는다. 푸시 후 1~2분 안에 반영된다.
