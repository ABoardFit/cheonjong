# 천종지자 — 화산의 시련

브라우저에서 바로 하는 화산 전투 시제품. **[게임 열기](https://aboardfit.github.io/cheonjong/)**

WASD/방향키 이동, 자동 검격, Space 경공, Esc 일시정지, Tab 능력치. 휴대폰은 전장을 누른 채 끌어 이동한다.

## 캐릭터 외형

기본은 백의다. 무공록에 투자한 세력 노드 수가 가장 많은 세력의 최신 외형을 사용하고, 동률이면 현재 선택한 해금 별호의 소속 세력이 동률에 포함될 때 그 외형을 선택한다. 공통 노드는 특정 세력 점수에 포함하지 않으며 별호로도 결정할 수 없으면 백의를 유지한다. 학습·회수·초기화·별호 변경·저장 복원 시 메인과 무공록·출전·통합 동작 비교의 외형이 함께 갱신된다.

기존 저장 트리에서 소속 정보가 빠진 사용자 제작 노드는 `tree-factions.js`의 검증된 ID 목록으로 복구한다. 원래 `tree.json`·`layout.json`은 유지하며, 편집기는 이후 `faction`도 저장한다. 세력별 전용 동작 애니메이션은 아직 없고 전신 원화에 좌우 전환·걷기 흔들림·피격 효과를 적용한다. 별도로 여는 남궁 연무 시제품은 기존 동작 원화를 유지한다.

메인의 **동작 비교**에서 **화산 / 남궁**을 선택한다. 남궁은 창궁무애검법·제왕검형·무한보1~7단계와 심법0~6성을 각각 비교하는 이미지 시연이다. 제왕검형7단계 제왕천림은 칼날 몸통을 화산 큰 꽃 지름의 약 절반 폭으로 그린다. 남궁은 아직 실제 전투 성장에 연결하지 않았으며 기존 화산 전투·무공록·수정 도구는 유지한다.

## 화면 수정 도구

어느 화면에서나 왼쪽 가장자리의 **✎ 수정** 탭으로 켠다(전투 중이면 일시정지된다). 각 부분에 이름표가 붙고, 눌러서 이름·글자·요청 메모를 적거나 끌어서 옮기고 크기를 바꾸고, 버튼·글·영역을 새로 넣을 수 있다.

- 선택: 누르기, Shift+클릭으로 더하기·빼기, 빈 곳을 끌어 여러 개. 이미 고른 것이 있으면 다른 요소를 눌러도 선택은 그대로이고(고른 것 안을 끌면 이동), 바꾸려면 이름표를 누른다.
- 정렬(좌·가로 중앙·우·상·세로 중앙·하)은 화면 또는 Alt+클릭한 기준 요소에 맞춘다. 순서 버튼으로 겹침 순서, 크기 점+Shift로 비율 유지, **묶음 해제**(Ctrl+Shift+G)로 묶음 안의 요소를 따로 다룬다.
- Ctrl+Z / Ctrl+Shift+Z(또는 Ctrl+Y)로 실행 취소·다시 실행.
- **수정 OFF**로 끌 때 바뀐 배치가 있으면 저장을 묻는다. **사이트에 저장**은 이 저장소의 `docs/layout.json`을 GitHub API로 고쳐 1~2분 뒤 모든 방문자에게 보이게 한다. 처음 한 번 저장 열쇠(Fine-grained token: 저장소 ABoardFit/cheonjong만, Contents: Read and write)를 넣으면 그 브라우저에 기억된다.
- 배치는 넓은 화면(961px 이상)과 휴대폰을 따로 저장한다.
- **요청 메모**는 사이트에 올라가지 않고 그 브라우저에만 남는다. 기능이 필요한 부탁은 메모를 적고 **요청서 복사**로 전달한다.

## 무공록 수정 도구

무공록(스킬 트리)을 연 뒤 위쪽의 **✎ 무공록 수정**으로 켠다.

- 노드를 누르면 한자·이름·설명·효과(한 줄에 하나, 예: `체력 +3%`)·종류·갈래가 보이고 고칠 수 있다. 요청 메모도 적는다.
- 끌어서 옮기면 줄이 따라 늘고 줄며, 다른 원을 피해 돌아간다. 돌아갈 길이 없으면 그 줄은 끊긴다. 연결이 없는 노드는 노랗게 빛난다.
- **연결**: 두 개를 고르면 잇는다. 여러 개를 한 노드에 이으려면 그 노드를 **Alt+클릭**해 중심으로 정한 뒤(금색 테두리) **중심에 연결**. 다시 Alt+클릭하면 중심이 풀린다.
- **연결 해제**: 고른 노드끼리 이어진 줄을 모두 끊는다(중심이 있으면 중심과의 줄만). **지우기**, Ctrl+Z / Ctrl+Shift+Z.
- **+ 노드**: 고른 노드가 있으면 그 근처(여럿이면 그 가운데)의 빈 자리에 만들어 고른 노드 모두와 잇고, 고른 노드가 같은 갈래면 갈래도 따른다. 없으면 화면 가운데에 연결 없이 만든다.
- 빈 곳을 끌면 영역 선택: 안의 노드가 골라지고, 그 영역을 어떻게 바꾸고 싶은지 메모한다.
- 화면 이동은 Space+끌기나 오른쪽 버튼 끌기, 확대는 휠.
- **끝내기** 때 바뀐 트리를 `docs/tree.json`(기본 트리와 다른 점만)으로 사이트에 저장한다(같은 저장 열쇠). 메모는 그 브라우저에만 남고 **요청서 복사**로 전달한다.

원본은 `editor/`에 있고 `publish.mjs`가 게임 페이지에 끼워 넣는다(`layout.json`·`tree.json`은 그대로 둔다).

## 갱신

현재 공개본은 `ba9aaaa`의 전투·연무장 변경을 기준으로, 홈페이지의 **세력 문양** 아래 **의상실**과 남녀 19종 비교 페이지를 `docs/`에 최소 변경으로 추가했다. 의상실은 별도 원화 열람·PNG 다운로드 페이지이며 게임의 성별 선택을 바꾸지 않는다.

과거 외형 연결 소스 `research/appearance-deploy-source`의 `4e7435f`는 현재 공개본 전체를 재현하지 못한다. 이 스냅샷이나 오래된 게임 HEAD로 `publish.mjs`를 실행하면 이후 전투 변경과 의상실이 소실될 수 있다. 전체 재배포 전에 최신 `docs/` 변경을 배포 소스에 모두 합쳐야 한다.

`docs/`는 GitHub Pages(main 브랜치 `/docs`)가 그대로 서비스한다. 이번 의상실은 최신 공개본에 직접 최소 패치를 적용했으며, 아래 전체 내보내기 절차는 최신 변경을 통합한 게임 저장소에만 사용한다. 사이트에서 저장한 배치(`docs/layout.json`)가 원격에 커밋되어 있으므로 먼저 받아 온다.

```bash
git pull --ff-only
node publish.mjs <게임 저장소 경로>
git add -A
git commit -m "deploy: 게임 <커밋>"
git push
```

`publish.mjs`는 게임 저장소 HEAD의 `prototype/dist`만 복사하며(QA 비교 페이지·이미지 프롬프트 제외) `docs/layout.json`은 그대로 둔다. 커밋하지 않은 작업은 올라가지 않는다. 푸시 후 1~2분 안에 반영된다.

화면 배치뿐 아니라 `docs/tree.json`과 `editor/`도 유지한다. 메인과 남궁 시연의 JS·CSS 주소, 동작 비교에서 불러오는 남궁 HTML 주소에는 콘텐츠 해시를 붙여 배포 후 이전 파일이 캐시에 섞이지 않도록 한다.
