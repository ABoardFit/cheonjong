# 천종지자 — 화산의 시련

브라우저에서 바로 하는 화산 전투 시제품. **[게임 열기](https://aboardfit.github.io/cheonjong/)**

WASD/방향키 이동, 자동 검격, Space 경공, Esc 일시정지, Tab 능력치. 휴대폰은 전장을 누른 채 끌어 이동한다.

## 화면 수정 도구

어느 화면에서나 왼쪽 가장자리의 **✎ 수정** 탭으로 켠다(전투 중이면 일시정지된다). 각 부분에 이름표가 붙고, 눌러서 이름·글자·요청 메모를 적거나 끌어서 옮기고 크기를 바꾸고, 버튼·글·영역을 새로 넣을 수 있다.

- 선택: 누르기, Shift+클릭으로 더하기·빼기, 빈 곳을 끌어 여러 개. 이미 고른 것이 있으면 다른 요소를 눌러도 선택은 그대로이고(고른 것 안을 끌면 이동), 바꾸려면 이름표를 누른다.
- 정렬(좌·가로 중앙·우·상·세로 중앙·하)은 화면 또는 Alt+클릭한 기준 요소에 맞춘다. 순서 버튼으로 겹침 순서, 크기 점+Shift로 비율 유지, **묶음 해제**(Ctrl+Shift+G)로 묶음 안의 요소를 따로 다룬다.
- Ctrl+Z / Ctrl+Shift+Z(또는 Ctrl+Y)로 실행 취소·다시 실행.
- **수정 OFF**로 끌 때 바뀐 배치가 있으면 저장을 묻는다. **사이트에 저장**은 이 저장소의 `docs/layout.json`을 GitHub API로 고쳐 1~2분 뒤 모든 방문자에게 보이게 한다. 처음 한 번 저장 열쇠(Fine-grained token: 저장소 ABoardFit/cheonjong만, Contents: Read and write)를 넣으면 그 브라우저에 기억된다.
- 배치는 넓은 화면(961px 이상)과 휴대폰을 따로 저장한다.
- **요청 메모**는 사이트에 올라가지 않고 그 브라우저에만 남는다. 기능이 필요한 부탁은 메모를 적고 **요청서 복사**로 전달한다.

원본은 `editor/`에 있고 `publish.mjs`가 게임 페이지에 끼워 넣는다.

## 갱신

`docs/`는 GitHub Pages(main 브랜치 `/docs`)가 그대로 서비스한다. 직접 고치지 말고 게임 저장소의 커밋에서 다시 내보낸다. 사이트에서 저장한 배치(`docs/layout.json`)가 원격에 커밋되어 있으므로 먼저 받아 온다.

```bash
git pull --ff-only
node publish.mjs <게임 저장소 경로>
git add -A
git commit -m "deploy: 게임 <커밋>"
git push
```

`publish.mjs`는 게임 저장소 HEAD의 `prototype/dist`만 복사하며(QA 비교 페이지·이미지 프롬프트 제외) `docs/layout.json`은 그대로 둔다. 커밋하지 않은 작업은 올라가지 않는다. 푸시 후 1~2분 안에 반영된다.
